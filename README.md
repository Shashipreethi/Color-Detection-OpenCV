# Color-Detection-OpenCV
🎨 Color Detection using OpenCV
A simple Python project that detects the name and RGB values of a color from an image. The user double-clicks on any color in the image, and the program finds the closest matching color from colors.csv and displays its name and RGB values.

▶️ Running Process
1.Open the project folder:
cd Color-Detection-OpenCV-main
2.Install required libraries:
pip install opencv-python pandas
3.Run the program:
python color_detection.py
4.The image will open. Double-click on any color to see its color name and RGB values.
